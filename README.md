# Customer_Shopping_Behavior_Analysis
Overview
This project is an end-to-end Data Analytics project focused on analyzing customer behavior, purchasing patterns, sales, revenue, and customer demographics.

The project covers the complete analytics workflow — from data loading and cleaning to SQL analysis, Power BI visualization, and report creation.

Dataset
The dataset contains customer and purchase-related information, including:

Customer demographics

Product categories

Purchase amounts

Sales and revenue

Subscription status

Review ratings

Shipping type

Age groups

Tools & Technologies
Python – Data cleaning, preprocessing & EDA

SQL / MySQL / SQL Server – Data querying and analysis

Power BI – Dashboard development and visualization

Excel/CSV – Dataset source

Jupyter Notebook – Python analysis

Project Steps
1. Data Loading
Loaded the raw dataset into Python using Pandas and inspected its structure, columns, and data types.

2. Data Cleaning
Handled missing values

Removed duplicates

Corrected data types

Standardized column values

Prepared clean data for analysis

3. Exploratory Data Analysis
Performed EDA using Python to identify:

Customer purchasing patterns

Category-wise sales

Revenue trends

Subscription behavior

Age-group performance

Review rating patterns

4. SQL Analysis
Loaded the cleaned dataset into MySQL/SQL Server and wrote SQL queries to extract key business insights using filtering, aggregation, grouping, and joins.

5. Power BI Dashboard
Created an interactive Power BI dashboard containing:

Total Customers

Average Purchase Amount

Average Review Rating

Revenue by Category

Sales by Category

Revenue by Age Group

Sales by Age Group

Subscription Status analysis

Interactive filters were added for customer segmentation and deeper analysis.

6. Report
Created a business-focused report summarizing the major findings from the Python analysis, SQL queries, and Power BI dashboard.

Dashboard
The Power BI dashboard provides an interactive view of customer behavior and business performance.

Key areas covered:

Customer overview

Sales & revenue analysis

Product category performance

Customer demographics

Subscription analysis

Shipping preferences

Results
The project provides a consolidated view of customer behavior and sales performance, helping identify patterns across product categories, age groups, subscription status, and customer segments.

How to Run
Python
Clone or download the repository.

Install the required Python libraries:

pip install pandas numpy matplotlib seaborn

Open the Jupyter Notebook.

Update the dataset path if required.

Run the notebook cells sequentially.

SQL
Create a database in MySQL or SQL Server.

Import the cleaned dataset.

Run the SQL scripts provided in the SQL folder.

Power BI
Open the .pbix file in Power BI Desktop.

Update the data source path if required.

Refresh the dataset.

Use the available filters and visuals to explore the dashboard.
